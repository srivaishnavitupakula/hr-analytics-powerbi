# 📊 HR Analytics Dashboard (Power BI)

## 📌 Project Overview
This project presents an interactive HR Analytics Dashboard built using Power BI. The dashboard analyzes employee data to uncover insights related to attrition, workforce distribution, job roles, and overall employee performance.

The goal of this project is to help HR teams make data-driven decisions to improve employee retention and organizational efficiency.

---

## 🛠 Tools & Technologies Used
- Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling
- Data Visualization

---

## 📈 Key Business Insights
- Overall employee attrition rate
- Department-wise attrition analysis
- Age group distribution of employees
- Job role performance insights
- Salary slab analysis
- Years at company vs attrition trends

---

## 📊 Dashboard Features
- Interactive slicers (Department, Gender, Education, etc.)
- KPI Cards (Total Employees, Attrition Rate, Average Age, etc.)
- Department-wise breakdown charts
- Attrition analysis by age and salary
- Dynamic filtering and drill-down capability
